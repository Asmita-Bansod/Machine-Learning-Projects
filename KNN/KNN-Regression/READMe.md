# 💼 Salary Prediction Using KNN Regression

## 📌 Project Overview

This project predicts an individual's **salary** based on professional and job-related factors using **K-Nearest Neighbors (KNN) Regression**.

## 🎯 Objective

To analyze salary-related factors and build a machine learning model that can predict salary based on employee characteristics.

## 📊 Dataset Features

* Job Title
* Experience Years
* Education Level
* Skills Count
* Industry
* Company Size
* Location
* Remote Work
* Certifications
* Salary (Target)

## 🔧 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* KNN Regression
* Jupyter Notebook

## 🚀 Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Encoding
5. Feature Analysis
6. Train-Test Split
7. KNN Regression
8. Model Evaluation

## 🔍 Key Insights

Experience, company size, job title, and education level showed stronger relationships with salary compared with other analyzed features. Experience had the highest observed correlation with salary.

## 📈 Conclusion

The project demonstrates how machine learning can be used to estimate salaries from professional attributes. KNN Regression provides a practical approach for salary prediction, while further improvements can be achieved through feature scaling, hyperparameter tuning, and model comparison.
