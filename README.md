Student Performance Prediction
📌 Project Overview

This project predicts a student's Performance Index using study habits, previous academic scores, sleep patterns, extracurricular activities, and practice-question performance.

🎯 Problem Statement

Predict student academic performance using:

Hours Studied
Previous Scores
Extracurricular Activities
Sleep Hours
Sample Question Papers Practiced
🛠️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
🔍 Project Workflow
Load the dataset
Perform exploratory data analysis
Check correlation and multicollinearity
Prepare features and target
Split data into training and testing sets
Train a Linear Regression model
Evaluate model performance
🤖 Machine Learning Model

Linear Regression

Target: Performance Index

Evaluation Metrics:

Mean Absolute Error (MAE)
Mean Squared Error (MSE)
R² Score

💡 Key Objective

The goal is to understand how student habits and previous academic performance influence the final Performance Index and build a model that can predict it.
