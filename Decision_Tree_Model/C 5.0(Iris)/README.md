# 🌳 C5.0 Decision Tree Classification - Machine Learning Project

## 📌 Project Overview

This project demonstrates an end-to-end Machine Learning workflow using the **C5.0 Decision Tree Classification algorithm**.

C5.0 is a decision tree-based classification algorithm used to predict categorical target variables.

The model builds a decision tree by selecting features that provide the best separation between classes.

---

# 🎯 Problem Statements

The objective of this project is to build a classification model using the **C5.0 algorithm** to predict a categorical target variable based on relevant input features.

### Example

Predict whether a customer will purchase a product based on:

- Age
- Income
- Previous Purchase
- Website Visits
- Membership Status

### Problem Type

- **Machine Learning Type:** Supervised Learning
- **Problem Type:** Classification
- **Algorithm:** C5.0 Decision Tree
