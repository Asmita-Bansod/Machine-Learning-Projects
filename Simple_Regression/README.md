# 📈 Simple Linear Regression - Machine Learning Project

## 📌 Project Overview

This project demonstrates an end-to-end **Simple Linear Regression** Machine Learning workflow.

The objective is to predict a continuous numerical target variable using a single independent variable.

### Example

Predicting **Salary** based on **Years of Experience**.

- **Independent Variable (X):** Years of Experience
- **Dependent Variable (Y):** Salary
- **Problem Type:** Regression
- **Learning Type:** Supervised Learning
- **Algorithm:** Simple Linear Regression

---

# 🎯 Problem Statement

The objective of this project is to build a Machine Learning model that predicts an employee's salary based on their years of experience.

The model learns the relationship between:

```text
Years of Experience → Salary
